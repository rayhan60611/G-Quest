# GreenQuest / NOVA — Eight Editable UI Designs

Visual system: Forest Green #2E7D32; Deep Forest #173820; Leaf Green #66BB6A; Warm Ivory #F2F7EE; Golden Reward #FFC107. The launcher and splash use the diagonal #358C3B-to-#19611E logo gradient.

Screen dimensions: 390 × 844 px (Android-first draft).

## Import to Figma
1. Open your Figma Design file.
2. Unzip this archive.
3. Drag each .svg onto the canvas. Figma imports it as editable vector shapes; text editability depends on Figma's SVG importer.
4. Arrange the screens by their 01–08 names.
5. Group or frame each screen as needed, and use native Figma text layers for final production.

## Project flows
User lifestyle → explainable rules-based challenge recommendations → join and self-report quest progress → view weekly activity estimates and GreenPoints → start next quest.

The mobile app's MVP recommender is rules-based; no trained ML model is represented as an app feature. The carbon estimate uses user-entered weekly quantities and illustrative prototype coefficients; it is not verified environmental savings. See `docs/carbon-estimation.md` for its formula, assumptions, and limitations.

Carbon insight screen is supporting, not the primary engagement goal.

Screen 08 illustrates the Challenge Progress completion state; it does not introduce a ninth UI screen.

Design-file numbers and distances are illustrative. In the app, activity estimates are calculated from user inputs using the documented prototype assumptions; these coefficients are not validated local emissions factors.
