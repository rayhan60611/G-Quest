# GreenQuest / NOVA

GreenQuest / NOVA is an Android-first, cross-platform habit and challenge app built with Expo, React Native, and TypeScript. It helps people explore small sustainability-related actions, track self-reported challenge progress, and view an indicative estimate from their own weekly travel and electricity inputs.

## Features

- **Profile setup:** Save a name, age, and sex; optionally choose a profile photo. If a photo is not selected, the app provides an animal avatar.
- **Lifestyle onboarding:** Answer a four-step questionnaire about travel, food, home habits, and available time.
- **Challenge recommendations:** See challenges ranked from questionnaire answers using a small, explainable, rule-based scoring system. Recommendations are not generated by machine learning.
- **Challenge library:** Browse and filter six sample challenges across Mobility, Food, and Energy.
- **Challenge tracking:** Join a challenge, log check-ins, see progress, and earn GreenPoints when a challenge is completed. Check-ins are self-reported.
- **Carbon insight:** Enter weekly car travel and home electricity use to see an indicative estimate, with category breakdowns.
- **Local persistence:** Profile, onboarding answers, activity inputs, challenge progress, activity history, and points are stored on the device.
- **Cross-platform UI:** Expo Router screens for Android, iOS, and web, with safe-area handling, status-bar adaptation, and animated screen transitions.
- **NOVA design system:** Light and dark surfaces with Midnight Navy, Electric Violet, Coral, Gold, Cyan, and Cloud palette tokens.

## Screens

| Route | Screen | What it does |
| --- | --- | --- |
| `/` | Welcome / profile setup | Collects required profile details, then starts onboarding or returns the user to their next step. |
| `/assessment` | Lifestyle assessment | Collects four single-select answers used to rank recommendations. |
| `/activity` | Weekly activity input | Collects car kilometres and home electricity use for the estimate. |
| `/home` | Home dashboard | Shows points, completed challenges, the active quest, and suggested challenges. |
| `/recommendations` | Smart recommendations | Displays answer-based ranked challenges and reasons for the ranking. |
| `/library` | Challenge library | Searches and filters the challenge catalog. |
| `/details/[id]` | Challenge details | Shows a selected challenge and lets the user join or resume it. |
| `/active` | Active progress | Shows the active challenge, check-ins, and progress toward its target. |
| `/completed` | Completion | Celebrates a completed challenge and shows points awarded. |
| `/insights` | Carbon insight | Displays the estimate based on saved weekly activity inputs. |
| `/profile` | Profile | Updates the user's saved profile and optional photo. |

The typical first-use flow is **profile → assessment → activity input → insights → home**. The bottom navigation provides **Home**, **Explore** (recommendations), **Active**, and **Impact** (insights). The Library and Challenge Details can be opened from relevant screens.

## Tech stack

- **Expo SDK 58** and **React Native 0.88** for native Android and iOS apps, plus web support.
- **TypeScript** for app and domain logic.
- **Expo Router** for file-based navigation and typed routes.
- **NativeWind v4** and **Tailwind CSS v3** for utility-class styling and shared design tokens.
- **React Native Reusables-style components** with `@rn-primitives` for accessible UI primitives.
- **Zustand 5** for in-memory application state.
- **Expo SQLite** for the current on-device database; **AsyncStorage** is used to migrate legacy onboarding data.
- **Expo Image Picker** and **Expo Image Manipulator** for optional profile photos.
- **React Native Reanimated** for screen animations.
- **Lucide React Native** and **React Native SVG** for icons and vector graphics.
- **Expo Linear Gradient**, **Expo Blur**, and **React Native Safe Area Context** for presentation and device insets.

## How it works

1. On startup, the app initializes `greenquest.db`, checks and applies schema migrations, and hydrates the Zustand store from SQLite.
2. A one-time migration imports legacy onboarding answers from AsyncStorage. New app data is written to SQLite.
3. The four assessment answers are evaluated by `lib/recommendations.ts`. Matching answers add points to relevant challenges; active and completed challenges are filtered out where possible.
4. Joining a challenge creates or resumes its progress record. Each successful check-in is saved to the local activity log. GreenPoints are awarded once when the challenge target is reached.
5. The carbon calculator in `lib/carbonCalculator.ts` validates weekly input and computes a category estimate using prototype coefficients. See [`docs/carbon-estimation.md`](docs/carbon-estimation.md) for formulas, limits, and caveats.

### Carbon estimate limitations

Carbon figures are **indicative prototype estimates**, not verified emissions measurements or claims of avoided emissions. The coefficients are team-selected assumptions, not validated location-specific factors. Challenge check-ins are self-reported, and GreenPoints reward participation only. Do not use these estimates for reporting, comparison, or decision-making.

## Project structure

```text
app/                 Expo Router routes and screens
components/nova/     NOVA screens, route layout, and avatar
components/ui/       Reusable UI components
docs/                Domain documentation
lib/                 Database, domain, calculator, and recommendation logic
store/               Zustand app store
assets/              App icons and splash assets
global.css           NativeWind entry and global styles
tailwind.config.js   NOVA Tailwind color tokens and theme
```

The native `android/` and `ios/` projects are generated by Expo Prebuild and are ignored by Git. Keep app configuration in `app.json` and Expo config plugins rather than hand-editing generated native files.

## Getting started

### Requirements

- Node.js supported by the installed Expo SDK (Node 24.3+ or Node 22.13+ is recommended).
- npm.
- For Android native runs: Android Studio / Android SDK and a device or emulator.
- For iOS native runs: macOS with Xcode and an iOS Simulator or device.

### Install and run

```bash
npm install
npm run start
```

From the Expo CLI, press `a` to open Android, `i` to open iOS Simulator, or `w` to open the web app. You can also use the project scripts:

```bash
npm run android
npm run ios
npm run web
```

## Tests and type checking

The test suite covers the calculator, recommendation ranking, profile validation, and anonymous profile behavior.

```bash
npm test
npx tsc --noEmit
```

## Android APK

The repository ignores generated native projects and APK build outputs. To generate an Android project and build locally:

```bash
npx expo prebuild --platform android
cd android
./gradlew assembleRelease
```

The APK is written to `android/app/build/outputs/apk/release/app-release.apk`. A locally generated APK may use a debug/test signing key; configure a release signing key before distributing it or publishing to Google Play.

For EAS cloud builds, authenticate with Expo first. The EAS profiles in `eas.json` include an internal Android APK profile and an iOS Simulator profile.

## Privacy and data

Profile details, optional profile photo data, assessment answers, activity inputs, challenge history, and points are stored locally on the device. The configured photo picker does not request camera or microphone access. This project does not claim that self-reported activity or prototype carbon estimates are independently verified.
